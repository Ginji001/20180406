# ハチロク手帳

GTD型タスク管理と毎日の記録を一つにした、インストール可能な日本語デジタル手帳PWAです。

## 主な機能

- 今日・次の7日間・受信箱・Next Action・Remind・Waiting・Projects・Wish List・完了・Overview
- 一覧・表・週・月の表示切り替え
- プロジェクト、タグ、優先度、期限、残り日数、メモ、繰り返し
- タスクの追加・編集・削除・完了
- 一括移動・先送り・完了、ドラッグ＆ドロップによる並べ替え
- 検索、タグ・優先度フィルター
- ドキュメントと習慣の管理
- 日ごとの気分・よかったこと・気づき・明日やることを残せる振り返り
- 記号で残せる予定・メモ・アイデア・完了・先送り・キャンセルのデイリーログ
- 月間目標と、予定・期限つきタスクを重ねて見られるカレンダー
- 6か月先までの未来の予定
- 欲しい物・読みたい物などを自由にまとめるコレクション
- 月別の予算・収入・支出を扱う家計簿
- 全データの件数確認、書き出し、復元ができるデータ管理
- 完了タスクと達成した習慣の自動集計、直近7日間・履歴表示
- JSONバックアップ・復元
- ライト／ダーク表示
- 端末内への自動保存
- オフライン対応
- iPhone、Mac、Windows対応
- Safari、Chrome、Edge、Firefoxなど主要な最新ブラウザに対応
- アプリ内の「使い方」ガイド

## 基本的な使い方

1. 思いついたタスクを受信箱へ追加します。
2. タスクを開き、Next Action・Remind・Waiting・Projects・Wish Listへ振り分けます。
3. 「今日」または「Next Action」を確認し、終わったタスクを完了します。
4. 必要に応じて一覧・表・週・月表示、一括移動、先送り、検索を使います。
5. 日中は種類を選んで予定やメモを残し、一日の終わりに「振り返り」で、できたことと明日やることを記録します。
6. 定期的にバックアップからJSONを書き出します。

## 公開

`main`または`master`ブランチへ反映すると、GitHub Actionsが`dist`フォルダをGitHub Pagesへ公開します。

GitHubリポジトリの「Settings → Pages → Build and deployment」で、Sourceを「GitHub Actions」に設定してください。

## データについて

すべての内容はブラウザの端末内ストレージに保存されます。ブラウザのデータを消去すると内容も削除されます。現在の版では端末間同期を行いません。
