# ハチロク手帳

バレットジャーナル風の、日本語のデジタル手帳PWAです（iPhone優先）。

- 公開URL：https://hachiroku-techo.pages.dev/
- 引き継ぎメモ：[ハチロク手帳_引き継ぎ.md](./ハチロク手帳_引き継ぎ.md)

## できること

- デイリーログ：記号を選んで一行で書く（メモ・アイデア・予定・出来事・行動など）。画像も添付できる
- マンスリーログ：ひと月の予定と期限のあるタスク、今月の目標、Googleカレンダーとの相互同期
- タスク：INBOX・次にやる・リマインダー・待ち状況・いつかやりたい・完了
- ハビット、コレクション、振り返り（気分）
- 端末間の同期（Googleログイン）、バックアップの書き出し・復元、オフライン対応

## 構成

- `dist/`：公開するファイル（ビルドなし）。`master` へ push すると Cloudflare Pages と GitHub Pages に公開される
- `sync-src/`：端末間同期（`dist/cloud-sync.js`）の元ソース

アプリのデータは端末内に保存され、このリポジトリには保存しません。
